# Conway's Game of Life 
 
Two C++/SFML implementations of Conway's Game of Life, built as university OOP assignments.
 
- [`conway/`](./conway) — class hierarchy, polymorphism, custom exceptions, static members.
- [`conway+/`](./conway+) — adds a generic `GenerationLog<T>` template and the Observer, Factory, and Singleton patterns.
Each subfolder has its own README with build and usage instructions.
